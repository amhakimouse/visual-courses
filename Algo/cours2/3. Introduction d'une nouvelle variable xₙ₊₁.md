
### 1. Idée : la nouvelle variable est-elle rentable ?

On a déjà les **prix duaux π** (valeur de chaque ressource). On calcule le coût de ressources qu'utiliserait la nouvelle variable et on le compare à son profit.

```
 Nouvelle variable xₙ₊₁ : coût cₙ₊₁ , colonne aₙ₊₁
                │
                ▼
   coût relatif :   c̄ₙ₊₁ = cₙ₊₁ − πᵀ·aₙ₊₁
                │
        ┌───────┴─────────┐
        ▼                 ▼
   c̄ ≥ 0               c̄ < 0
   pas rentable        rentable
   x* inchangée        xₙ₊₁ entre en base
   (xₙ₊₁ = 0)          1) calculer  āₙ₊₁ = B⁻¹·aₙ₊₁
                       2) ajouter la colonne au tableau
                       3) simplexe primal (ratio sur āₙ₊₁)
```

### 2. Exemple du cours

On ajoute **x₇** : colonne a₇ = (2, 5, 0)ᵀ et profit 2 (coût c₇ = −2 dans l'écriture du cours).

```
 max z = 5x₁ + 4,5x₂ + 6x₃ + 2x₇
 sous   6x₁ +  5x₂ +  8x₃ + 2x₇ ≤ 60
       10x₁ + 20x₂ + 10x₃ + 5x₇ ≤ 150
        x₁                      ≤ 8
```

#### Étape 1 : coût relatif

Prix duaux lus sous les écarts : **y = (11/14 , 1/35 , 0)**, soit π = (−11/14, −1/35, 0) dans l'écriture du cours.

```
 Ressources consommées par x₇ :  (11/14)·2 + (1/35)·5 + 0·0 = 11/7 + 1/7 = 12/7 ≈ 1,71
 Profit de x₇                  :  2

   profit 2  >  coût des ressources 1,71     ✔ rentable

 c̄₇ = c₇ − πᵀa₇ = −2 + 12/7 = −2/7 < 0   →   x₇ entre en base
```

```
  profit de x₇
  ───┬──────────────┬────────────┬──────────►
    0            12/7≈1,71       2
     │◄─ non rentable (c̄ ≥ 0) ─►│◄─ rentable
                    seuil
```

#### Étape 2 : colonne dans le tableau courant

```
 ā₇ = B⁻¹·a₇  = [  −1/7   3/35  0 ] [2]   [  1/7  ]  ← ligne x₂
                [  −2/7   1/14  1 ] [5] = [ −3/14 ]  ← ligne x₆
                [   2/7  −1/14  0 ] [0]   [  3/14 ]  ← ligne x₁
```

|Base|x₇ (ā₇)|b|Ratio|
|---|---|---|---|
|**x₂**|**[1/7]**|30/7|(30/7)/(1/7) = **30** ◄|
|x₆|−3/14|11/7|∅ (négatif)|
|x₁|3/14|45/7|(45/7)/(3/14) = **30** ◄|
|**−z**|−2/7|360/7||

Les deux ratios valent 30 (**égalité, donc dégénérescence**). On choisit **x₂ qui sort**, pivot = 1/7.

#### Étape 3 : après pivotage

|Base|x₁|x₂|x₃|x₄|x₅|x₆|x₇|b|
|---|---|---|---|---|---|---|---|---|
|x₇|0|7|−2|−1|3/5|0|1|30|
|x₆|0|3/2|−2|−1/2|1/5|1|0|8|
|x₁|1|−3/2|2|1/2|−1/5|0|0|**0**|
|**z**|0|2|**0**|1/2|1/5|0|0|**60**|

Tous les coûts relatifs sont ≥ 0, donc **optimum** :

> **x₇ = 30, x₆ = 8, x₁ = x₂ = x₃ = 0, z* = 60** (contre 360/7 ≈ 51,43 avant)

Vérification : 2·30 = 60 ✔, 5·30 = 150 ✔, z = 2·30 = 60 ✔. x₁ reste en base à 0 (effet de la dégénérescence).

Les prix duaux deviennent y = (1/2, 1/5, 0). Ils ont changé, car la base a changé.

### 4. À retenir

| Test                                | Conclusion                                                 |
| ----------------------------------- | ---------------------------------------------------------- |
| c̄ₙ₊₁ = cₙ₊₁ − πᵀaₙ₊₁ ≥ 0           | La variable n'est pas rentable, x* inchangée               |
| c̄ₙ₊₁ < 0                           | Elle entre en base : calculer B⁻¹aₙ₊₁ puis simplexe primal |
| Ratios égaux au pivot               | Dégénérescence : une variable de base reste à 0            |
| Cas 3 (colonne modifiée, hors base) | Même test avec la nouvelle colonne                         |

### 1. Idée

Changer bᵣ ne touche **pas la ligne −z** (les coûts relatifs restent ≥ 0, donc l'optimalité est conservée). Seul le **vecteur b̄ = B⁻¹b** bouge, donc c'est l'**admissibilité** qui est en jeu.

```
 bᵣ ──► bᵣ + Δbᵣ
          │
          ▼
  nouveau b̄ᵢ = b̄ᵢ + βᵢᵣ · Δbᵣ        (βᵢᵣ = colonne de B⁻¹ associée à la contrainte r,
          │                              c'est la colonne de l'écart de la contrainte r)
   ┌──────┴─────────────┐
   ▼                    ▼
 tous b̄ᵢ ≥ 0         un b̄ᵢ < 0
 même base,           base non admissible
 x* et z changent     → simplexe DUAL
```

**Intervalle de validité (formule du cours) :**

```
 max{ −b̄ᵢ/βᵢᵣ : βᵢᵣ > 0 }  ≤  Δbᵣ  ≤  min{ −b̄ᵢ/βᵢᵣ : βᵢᵣ < 0 }
```

### 2. Exemple : on modifie b₂ = 150 (contrainte C2)
![[Pasted image 20261005120634.png|466]]
La colonne de B⁻¹ pour C2 est celle de **x₅** (l'écart de C2) :

|Ligne|b̄ᵢ|βᵢ₂ (col. x₅)|Nouveau b̄ᵢ|
|---|---|---|---|
|x₂|30/7|3/35|30/7 + (3/35)Δ|
|x₆|11/7|1/14|11/7 + (1/14)Δ|
|x₁|45/7|−1/14|45/7 − (1/14)Δ|

On impose b̄ᵢ ≥ 0 sur chaque ligne :

```
 βᵢ₂ > 0 :  Δ ≥ −(30/7)/(3/35) = −50        (ligne x₂)
            Δ ≥ −(11/7)/(1/14) = −22        (ligne x₆)   ◄ max = −22
 βᵢ₂ < 0 :  Δ ≤ (45/7)/(1/14)  = 90         (ligne x₁)   ◄ min = 90

                    −22 ≤ Δb₂ ≤ 90
```

### 3. Lecture sur b₂

```
  b₂ (ressource de C2)
  ───┬─────────────┬────────────┬──────────────┬────►
    128           150          240
     │◄──── base {x₂, x₆, x₁} reste admissible ────►│
     │                                              │
  x₆ devient < 0                              x₁ devient < 0
```

Dans cet intervalle, **la base ne change pas**, et z varie de façon linéaire :

```
 z(b₂) = 360/7 + (1/35)·Δb₂        ← 1/35 = c̄₅ = prix dual y₂ de la contrainte C2
```

Chaque unité de ressource C2 en plus rapporte **1/35 ≈ 0,029** de profit, tant que b₂ ∈ [128 ; 240].

### 4. Deux tests

**Test A : b₂ = 160 (Δ = +10, dans l'intervalle)**

```
 x₂ = 30/7 + 30/35 = 36/7     x₆ = 11/7 + 10/14 = 16/7     x₁ = 45/7 − 10/14 = 40/7
 z  = 360/7 + 10/35 = 362/7 ≈ 51,71
```

Vérification : 6·(40/7) + 5·(36/7) = 60 ✔ et 10·(40/7) + 20·(36/7) = 160 ✔

**Test B : b₂ = 100 (Δ = −50 < −22, hors intervalle)**

```
 x₂ = 30/7 − 150/35 = 0     x₁ = 45/7 + 50/14 = 10     x₆ = 11/7 − 50/14 = −2  ✘
```

La base est non admissible (x₆ < 0) mais la ligne −z est toujours ≥ 0 : c'est la situation du **simplexe dual**.

|Base|x₁|x₂|x₃|x₄|x₅|x₆|b|
|---|---|---|---|---|---|---|---|
|x₂|0|1|−2/7|−1/7|3/35|0|0|
|**x₆**|0|0|**[−11/7]**|−2/7|1/14|1|**−2** ◄ sort|
|x₁|1|0|11/7|2/7|−1/14|0|10|
|**z**|0|0|4/7|11/14|1/35|0|50|
|ratio \|c̄/a\||||**(4/7)/(11/7) = 4/11** ◄ min|(11/14)/(2/7) = 11/4||||

x₆ sort, x₃ entre (pivot −11/7). On obtient :

|Base|x₁|x₂|x₃|x₄|x₅|x₆|b|
|---|---|---|---|---|---|---|---|
|x₂|0|1|0|−1/11|4/55|−2/11|4/11|
|x₃|0|0|1|2/11|−1/22|−7/11|14/11|
|x₁|1|0|0|0|0|1|8|
|**z**|0|0|0|15/22|3/55|4/11|542/11|

Tous les b ≥ 0, donc **optimum** : x₁ = 8, x₂ = 4/11, x₃ = 14/11, **z = 542/11 ≈ 49,27**.

Vérification : 6·8 + 5·(4/11) + 8·(14/11) = 60 ✔ et 10·8 + 20·(4/11) + 10·(14/11) = 100 ✔

```
 Remarque : le dual a fait baisser z de 50 (valeur fictive, non admissible)
 vers 49,27 (valeur réelle).
```

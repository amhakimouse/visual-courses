

### 1. Idée

Si xⱼᵣ est **en base**, son coût apparaît dans c_B, donc **π = c_B B⁻¹ change** et **toute la ligne −z est affectée**, pas une seule colonne.

```
 c_{jr} ──► c_{jr} + Δc
              │
              ▼
  chaque coût relatif hors base devient :   c̃ⱼ = c̄ⱼ − Δc · aᵣⱼ
                                            (aᵣⱼ = ligne r de la variable modifiée)
              │
      ┌───────┴────────────┐
      ▼                    ▼
  tous c̃ⱼ ≥ 0          un c̃ⱼ < 0
  mêmes x*, z change   xⱼ entre en base → simplexe primal
```

**Contrainte : c̃ⱼ ≥ 0 pour tout j hors base**, ce qui donne un **double encadrement** selon le signe de aᵣⱼ :

```
 aᵣⱼ > 0 :  Δc ≤ c̄ⱼ / aᵣⱼ        (borne SUPÉRIEURE, on prend le min)
 aᵣⱼ < 0 :  Δc ≥ c̄ⱼ / aᵣⱼ        (borne INFÉRIEURE, on prend le max)
```

### 3. Lecture en profit

Dans le cours, le coût de x₁ vaut −5 (écriture de −z), donc **p₁ = 5 − Δc**. Les bornes s'inversent :

```
 p₁ ∈ [ 5 − 4/11 ; 5 + 2/5 ] = [ 51/11 ; 27/5 ] ≈ [ 4,64 ; 5,40 ]

  p₁ (profit de x₁)
  ──┬────────┬───────────┬────────────┬─────────►
   4,64      5          5,40
    │◄── x* = (45/7, 30/7, 0) reste optimale ──►│
    │                                           │
 x₃ entre en base                         x₅ entre en base
```

Les bornes viennent de **deux variables différentes** : x₃ bloque à gauche, x₅ à droite.

### 4. Deux tests

**Test A : p₁ = 5,3 (Δc = −0,3, dans l'intervalle)**

```
 Mêmes variables : x₁ = 45/7, x₂ = 30/7, x₃ = 0
 Seul z change : z = 5,3·(45/7) + 4,5·(30/7) = 373,5/7 ≈ 53,36
 (contrôle : 51,43 + 0,3·45/7 = 53,36 ✔)
```

**Test B : p₁ = 6 (Δc = −1, hors intervalle, car p₁ > 5,40)**

```
 c̃₅ = c̄₅ − Δc·a₁₅ = 1/35 − (−1)(−1/14) = 1/35 − 1/14 = −3/70 < 0  ✘
 c̃₃ = 4/7 + 11/7 = 15/7 ≥ 0 ✔      c̃₄ = 11/14 + 2/7 = 15/14 ≥ 0 ✔
 → x₅ entre en base
```

Colonne de x₅ : (3/35, 1/14, −1/14). On compare les ratios sur les coefficients > 0 :

| Ligne  | bᵢ   | aᵢ₅   | Ratio        |
| ------ | ---- | ----- | ------------ |
| x₂     | 30/7 | 3/35  | 50           |
| **x₆** | 11/7 | 1/14  | **22** ◄ min |
| x₁     | 45/7 | −1/14 | ∅            |

### 1. Idée

Si xⱼ est **hors base**, changer son coût ne touche **que sa propre ligne −z**. Les multiplicateurs πᵀ = c_BᵀB⁻¹ ne dépendent que des variables de base, donc ils ne bougent pas.

```
 cⱼ  ──►  c̃ⱼ = cⱼ + Δcⱼ        (x_B, c_B, B⁻¹, π : inchangés)
              │
              ▼
   seul le coût relatif de xⱼ change :   c̃ⱼ(relatif) = c̄ⱼ + Δcⱼ
              │
      ┌───────┴────────────┐
      ▼                    ▼
 c̃ⱼ(rel.) ≥ 0         c̃ⱼ(rel.) < 0
 x* reste optimale    xⱼ entre en base → on continue avec le simplexe primal
```

**Condition de validité (formule du cours) :** **Δcⱼ ≥ −c̄ⱼ**

### 2. Exemple du cours

Ici l'écriture est celle du cours : on minimise −z, donc les coûts valent −5, −4,5, −6.

```
 max z = 5x₁ + 4,5x₂ + 6x₃
 sous   6x₁ +  5x₂ +  8x₃ ≤ 60
       10x₁ + 20x₂ + 10x₃ ≤ 150
        x₁                ≤ 8
```

**Tableau optimal** (x₃ est hors base) :

|Base|x₁|x₂|x₃|x₄|x₅|x₆|b|
|---|---|---|---|---|---|---|---|
|x₂|0|1|−2/7|−1/7|3/35|0|30/7|
|x₆|0|0|−11/7|−2/7|1/14|1|11/7|
|x₁|1|0|11/7|2/7|−1/14|0|45/7|
|**−z**|0|0|**4/7**|11/14|1/35|0|360/7|

Solution : x₁ = 45/7, x₂ = 30/7, x₃ = 0, z = 360/7 ≈ 51,43.

**Coût relatif de x₃ : c̄₃ = 4/7.** Il mesure la « marge » avant que x₃ devienne intéressante.

### 3. Intervalle de validité

```
 Δc₃ ≥ −c̄₃ = −4/7

 Dans l'écriture du cours (coût de −z) :   c₃ = −6  →  c₃ + Δc₃ ≥ −6 − 4/7 = −46/7
 En profit (max z)                       :  profit p₃ = 6 + δ  ≤  6 + 4/7 = 46/7 ≈ 6,57

        profit p₃ de x₃
  ──────┬────────────┬──────────┬────────────►
        5            6        46/7≈6,57
  ◄──── x* reste optimale ────►│◄── x₃ entre en base
         (x₃ = 0)              │
                          seuil critique
```

On peut **baisser** le profit de x₃ autant qu'on veut (x₃ reste hors base, δ → −∞), mais on ne peut l'**augmenter** que de 4/7 ≈ 0,57.

### 4. Deux tests

**Test A : p₃ = 6,5 (δ = +0,5 ≤ 4/7)**

```
 c̄₃ = 4/7 − 0,5 = 1/14 ≥ 0  ✔  →  x* inchangée : x₁=45/7, x₂=30/7, x₃=0
 (z ne change pas non plus, car x₃ = 0)
```

**Test B : p₃ = 7 (δ = +1 > 4/7)**

```
 c̄₃ = 4/7 − 1 = −3/7 < 0  ✘  →  x₃ entre en base
```

Colonne de x₃ : (−2/7, −11/7, **11/7**). Un seul coefficient est > 0, dans la ligne x₁.

```
 ratio = (45/7) / (11/7) = 45/11 ≈ 4,09   →  x₁ sort, pivot = 11/7
```

### 5. À retenir

|Cas|Conclusion|
|---|---|
|Δcⱼ ≥ −c̄ⱼ|x* reste optimale (z inchangé, car xⱼ = 0)|
|Δcⱼ < −c̄ⱼ|xⱼ entre en base : reprise par le simplexe primal|
|Variable hors base|Une seule colonne à mettre à jour|

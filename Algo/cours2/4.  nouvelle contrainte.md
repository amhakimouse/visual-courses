
### 1. Idée : la solution actuelle respecte-t-elle la nouvelle contrainte ?

Ajouter une contrainte ne change **ni les coûts relatifs**, ni les anciennes contraintes. Seule l'**admissibilité** peut se perdre : le sommet optimal peut se retrouver du mauvais côté de la nouvelle coupe.

```
 Nouvelle contrainte : Σ aₘ₊₁,ⱼ xⱼ ≤ bₘ₊₁   (+ écart xₙ₊₁ en base, ligne m+1)
                │
   étape 1 : éliminer les variables de base de la nouvelle ligne
             āₘ₊₁,ⱼ = aₘ₊₁,ⱼ − Σᵣ aₘ₊₁,jᵣ · ārⱼ
             b̄ₘ₊₁   = bₘ₊₁  − Σᵣ aₘ₊₁,jᵣ · b̄ᵣ
                │
        ┌───────┴──────────┐
        ▼                  ▼
   b̄ₘ₊₁ ≥ 0            b̄ₘ₊₁ < 0
   x* respecte la      x* viole la contrainte
   contrainte          → simplexe DUAL (xₙ₊₁ sort)
   x* inchangée
```

### 2. Exemple du cours (type ≤)

On ajoute **2x₁ + 3x₂ + x₃ ≤ 25**, avec l'écart x₇.

**Test direct :** x* = (45/7, 30/7, 0) donne 2·(45/7) + 3·(30/7) = 180/7 ≈ **25,71 > 25**. La contrainte est violée.

#### Étape 1 : ligne ajoutée, puis nettoyée

Dans la ligne x₇ il reste des coefficients sur x₁ (2) et x₂ (3), qui sont en base. On retire 3 × (ligne x₂) et 2 × (ligne x₁) :

```
 x₃ :  1 − 3·(−2/7) − 2·(11/7)     = −9/7
 x₄ :  0 − 3·(−1/7) − 2·(2/7)      = −1/7
 x₅ :  0 − 3·(3/35) − 2·(−1/14)    = −4/35
 b  : 25 − 3·(30/7) − 2·(45/7)     = −5/7   ✘ négatif
```

|Base|x₁|x₂|x₃|x₄|x₅|x₆|x₇|b|
|---|---|---|---|---|---|---|---|---|
|x₂|0|1|−2/7|−1/7|3/35|0|0|30/7|
|x₆|0|0|−11/7|−2/7|1/14|1|0|11/7|
|x₁|1|0|11/7|2/7|−1/14|0|0|45/7|
|**x₇**|0|0|−9/7|−1/7|**[−4/35]**|0|1|**−5/7** ◄ sort|
|**−z**|0|0|4/7|11/14|1/35|0|0|360/7|
|ratio \|c̄/a\||||(4/7)/(9/7) = 4/9 ≈ 0,44|11/2|**(1/35)/(4/35) = 1/4** ◄ min||||

x₇ sort, **x₅ entre**, pivot = −4/35 (règle du dual).

#### Étape 2 : après pivotage

|Base|x₁|x₂|x₃|x₄|x₅|x₆|x₇|b|
|---|---|---|---|---|---|---|---|---|
|x₂|0|1|−5/4|−1/4|0|0|3/4|15/4|
|x₆|0|0|−19/8|−3/8|0|1|5/8|9/8|
|x₁|1|0|19/8|3/8|0|0|−5/8|55/8|
|x₅|0|0|45/4|5/4|1|0|−35/4|25/4|
|**−z**|0|0|1/4|3/4|0|0|1/4|**205/4**|

Tous les b ≥ 0 et tous les coûts relatifs ≥ 0, donc **optimum** :

> **x₁ = 55/8, x₂ = 15/4, x₃ = 0, z* = 205/4 = 51,25** (avant : 360/7 ≈ 51,43)

Vérification : 2·(55/8) + 3·(15/4) = 25 ✔ et 6·(55/8) + 5·(15/4) = 60 ✔

```
 z
 51,43 ┤ ██ avant (sans la contrainte)
 51,25 ┤ ██ ██ après  → la contrainte coûte 0,18
```

Ajouter une contrainte ne peut que **dégrader** (ou laisser égal) l'optimum d'un problème de max.

### 3. Les trois variantes du cours

|Type|Écart|Traitement|Test|
|---|---|---|---|
|**a) ≤**|+ xₙ₊₁|Éliminer les variables de base|b̄ₘ₊₁ ≥ 0 → x* reste optimale|
|**b) ≥**|− xₙ₊₁|Idem, puis **multiplier la ligne par −1**|−b̄ₘ₊₁ ≥ 0 → x* reste optimale|
|**c) =**|aucun|Idem, puis **pivot dual sur un élément négatif** de la ligne (ratio max c̄ⱼ/āₘ₊₁,ⱼ avec ā < 0)|b̃ᵢ ≥ 0 pour tout i → optimum|

**Exemple b)** : 2x₁ + 3x₂ + x₃ ≥ 25. On obtient la même ligne que plus haut, multipliée par −1, avec b̄ = **+5/7 ≥ 0**. La solution x* = (45/7, 30/7, 0) est donc **toujours optimale** (180/7 ≥ 25 ✔), et la variable de surplus vaut 5/7.

**Exemple c)** : 2x₁ + 3x₂ + x₃ = 25. Il n'y a pas d'écart pour servir de base : on pivote directement sur x₅ (ratio 1/4, même choix que ci-dessus). On retrouve le même optimum, x₁ = 55/8, x₂ = 15/4, z = 205/4.

### 4. À retenir

| Situation                                  | Conclusion                                                            |
| ------------------------------------------ | --------------------------------------------------------------------- |
| Nouvelle contrainte déjà satisfaite par x* | x* reste optimale                                                     |
| Violée (b̄ₘ₊₁ < 0)                         | Simplexe dual, la ligne ajoutée donne la variable sortante            |
| Effet sur z                                | Jamais une amélioration (max)                                         |
| Lien avec l'ajout de variable              | Dualité : **nouvelle variable ↔ nouvelle contrainte** (primal ↔ dual) |

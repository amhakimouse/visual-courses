Étape 0 — Rappel de Cours (Pour tout comprendre facilement)

Les 4 Concepts Clés expliqués par l'image

1. Relaxation Continue

On oublie d'abord « entiers »

Le Simplexe ne sait pas gérer les nombres entiers directement. On résout donc d'abord avec des nombres à virgule ($x_1, x_2 \in \mathbb{R}^+$). Si la solution finale tombe sur des entiers, on a gagné ! Sinon, on coupe.

2. Coupe de Gomory

Le « Couteau Chirurgical »

Quand le sommet optimal a une coordonnée à virgule (ici $x_1 = 0,5$), on ajoute une nouvelle contrainte qui tranche ce coin à virgule sans jamais couper le moindre point entier vert !

3. Piège Partie Fractionnaire

Toujours positive ($f \ge 0$) !

Tout nombre s'écrit $a = \lfloor a \rfloor + f$ avec $0 \le f < 1$. Attention aux nombres négatifs : -1/2 = -1 + 1/2 Sa partie fractionnaire est $+1/2$ (et jamais $-1/2$).

4. Simplexe Dual

Réparer un second membre négatif

La coupe ajoute une ligne avec un second membre négatif ($e_3 = -1/2 < 0$). Le Simplexe Dual fait sortir cette variable négative pour ramener la solution sur le point entier optimal.

🎬 Schéma SVG Animé : Pourquoi la décomposition de $-\frac{1}{2}$ donne $-1 + \frac{1}{2}$ ?

C'est l'erreur n°1 en examen ! Pour trouver la partie entière $\lfloor a \rfloor$, on descend toujours vers l'entier à gauche sur l'axe des nombres, puis on remonte d'une fraction positive $f \in [0, 1[$.

⚠️ Règle d'Or de Gomory : $0 \le f < 1$

Question 2 — Anatomie Visuelle de la Coupe

2. Calculer la coupe correspondant à la variable de base $x_1$

Ligne génératrice : $x_1 + \frac{1}{2}e_1 - \frac{1}{2}e_2 = \frac{1}{2}$

🔬 Schéma SVG : Décomposition terme par terme en $\lfloor a \rfloor + f$ (avec $0 \le f < 1$)

1. Rédaction de la coupe en variables d'écart (pour Q4)

On part de la ligne de base de $x_1$ dans le tableau optimal : $$x_1 + \frac{1}{2}e_1 - \frac{1}{2}e_2 = \frac{1}{2}$$ En décomposant chaque coefficient en partie entière + partie fractionnaire positive : $$x_1 + \left(0 + \frac{1}{2}\right)e_1 + \left(-1 + \frac{1}{2}\right)e_2 = 0 + \frac{1}{2}$$ $$\underbrace{x_1 - e_2}_{\text{entier}} + \frac{1}{2}e_1 + \frac{1}{2}e_2 = \frac{1}{2}$$ La coupe de Gomory s'écrit donc : $$\frac{1}{2}e_1 + \frac{1}{2}e_2 \ge \frac{1}{2} \iff -\frac{1}{2}e_1 - \frac{1}{2}e_2 \le -\frac{1}{2}$$ Avec la variable d'écart $e_3 \ge 0$ : $$\mathbf{-\frac{1}{2}e_1 - \frac{1}{2}e_2 + e_3 = -\frac{1}{2}}$$

2. Traduction en variables $(x_1, x_2)$ (pour Q3)

Pour tracer cette coupe sur le graphique de la Question 3, on remplace $e_1$ et $e_2$ par leurs expressions en fonction de $x_1$ et $x_2$ : $$\begin{cases} e_1 = 3 - 2x_1 - x_2 \\ e_2 = 2 - x_2 \end{cases}$$ En injectant dans $\frac{1}{2}e_1 + \frac{1}{2}e_2 \ge \frac{1}{2}$ (soit $e_1 + e_2 \ge 1$) : $$(3 - 2x_1 - x_2) + (2 - x_2) \ge 1$$ $$5 - 2x_1 - 2x_2 \ge 1 \iff 2x_1 + 2x_2 \le 4$$ En divisant par $2$, on obtient l'équation géométrique de la coupe : $$\mathbf{x_1 + x_2 \le 2}$$

Question 4 — Résolution Algébrique

4. Résoudre le même PL en utilisant l'algorithme Dual du Simplexe

Base $x_1$ $x_2$ $e_1$ $e_2$ $e_3$ (Coupe) $b_i$

Rédaction Examen (Question 4)

1) Variable sortante (Critère de réalisabilité) :

On insère la coupe $-\frac{1}{2}e_1 - \frac{1}{2}e_2 + e_3 = -\frac{1}{2}$ dans le tableau optimal. La variable de base $e_3$ a un second membre négatif ($b_{e_3} = -1/2 < 0$) : $e_3$ sort de la base.

2) Variable entrante (Règle des ratios duaux) :

On compare les rapports $\left|\frac{c_j - z_j}{a_{3j}}\right|$ uniquement pour les colonnes ayant un coefficient strictement négatif ($a_{3j} < 0$) sur la ligne de $e_3$ :

$$\min_{a_{3j} < 0} \left\{ \underbrace{\left|\frac{-1/2}{-1/2}\right|}_{= 1 \text{ (col. } e_1\text{)}} \; , \; \underbrace{\left|\frac{-3/2}{-1/2}\right|}_{= 3 \text{ (col. } e_2\text{)}} \right\} = 1$$

Le minimum est atteint pour $e_1$ : $e_1$ entre dans la base. Le pivot est $a_{3,e_1} = -\frac{1}{2}$.

3) Lecture du nouveau tableau après pivotage :

Après pivotage, tous les seconds membres sont positifs ou nuls ($x_1 = 0, x_2 = 2, e_1 = 1$) et tous les coûts réduits sont négatifs ou nuls. On retrouve exactement la solution optimale entière : $$\mathbf{x_1^* = 0, \quad x_2^* = 2, \quad Z^* = 4}$$

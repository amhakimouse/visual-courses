Modification d'un coefficient de la fonction objectif d'une variable en base $x_1$


La variable $x_1$ est à la **ligne 3** du tableau[cite: 2]. Son coefficient actuel est $c_1 = 1$. Soit $c_1'$ le nouveau coefficient, avec $\Delta c_1 = c_1' - 1$.

- **Pour la variable hors-base $x_4$ :**
    
    $$\bar{c}_4' = \frac{4}{5} - \Delta c_1 \cdot \left(\frac{1}{5}\right) \ge 0 \implies \frac{4}{5} \ge \frac{1}{5}\Delta c_1 \implies \Delta c_1 \le 4$$
    
- **Pour la variable hors-base $x_5$ :**
    
    $$\bar{c}_5' = \frac{3}{5} - \Delta c_1 \cdot \left(\frac{2}{5}\right) \ge 0 \implies \frac{3}{5} \ge \frac{2}{5}\Delta c_1 \implies \Delta c_1 \le \frac{3}{2} = 1.5$$
    

On combine les deux contraintes : $\Delta c_1 \le 1.5$. Comme $\Delta c_1 = c_1 - 1 \le 1.5$, alors $c_1 \le 2.5$. En regardant s'il y a une borne inférieure (ici aucune variable n'a un coefficient qui imposerait $\Delta c_1 \ge \text{valeur négative}$ bloquante), on trouve :

$$c_1 \in ]-\infty, 2.5]$$


### 1. Idée

la solution actuelle reste optimale tant que les coûts réduits des variables hors-base $(e_1, e_2)$ sur la ligne $z$ (c'est-à-dire **$C_B B^{-1}$**) restent $\geq 0$ :
$C_B$ : les coûts réduits des $vars$ de $Z$


```
 c_{jr} ──► c_{jr} + Δc
              │
              ▼
  chaque coût relatif hors base devient :   c̃ⱼ = c̄ⱼ − Δc · aᵣⱼ
                                (aᵣⱼ = ligne r de la variable modifiée)
              │
      ┌───────┴────────────┐
      ▼                    ▼
  tous c̃ⱼ ≥ 0          un c̃ⱼ < 0
  mêmes x*, z change   xⱼ entre en base → simplexe primal
```

**Contrainte : c̃ⱼ ≥ 0 pour tout j hors base**, ce qui donne un **double encadrement** selon le signe de aᵣⱼ :

```
 aᵣⱼ > 0 :  Δc ≤ c̄ⱼ / aᵣⱼ        (borne SUPÉRIEURE, on prend le min)
 aᵣⱼ < 0 :  Δc ≥ c̄ⱼ / aᵣⱼ        (borne INFÉRIEURE, on prend le max)
```

### 3. Lecture en profit

Dans le cours, le coût de x₁ vaut −5 (écriture de −z), donc **p₁ = 5 − Δc**. Les bornes s'inversent :

```
 p₁ ∈ [ 5 − 4/11 ; 5 + 2/5 ] = [ 51/11 ; 27/5 ] ≈ [ 4,64 ; 5,40 ]

  p₁ (profit de x₁)
  ──┬────────┬───────────┬────────────┬─────────►
   4,64      5          5,40
    │◄── x* = (45/7, 30/7, 0) reste optimale ──►│
    │                                           │
 x₃ entre en base                         x₅ entre en base
```

Les bornes viennent de **deux variables différentes** : x₃ bloque à gauche, x₅ à droite.

### 4. Deux tests

**Test A : p₁ = 5,3 (Δc = −0,3, dans l'intervalle)**

```
 Mêmes variables : x₁ = 45/7, x₂ = 30/7, x₃ = 0
 Seul z change : z = 5,3·(45/7) + 4,5·(30/7) = 373,5/7 ≈ 53,36
 (contrôle : 51,43 + 0,3·45/7 = 53,36 ✔)
```

**Test B : p₁ = 6 (Δc = −1, hors intervalle, car p₁ > 5,40)**

```
 c̃₅ = c̄₅ − Δc·a₁₅ = 1/35 − (−1)(−1/14) = 1/35 − 1/14 = −3/70 < 0  ✘
 c̃₃ = 4/7 + 11/7 = 15/7 ≥ 0 ✔      c̃₄ = 11/14 + 2/7 = 15/14 ≥ 0 ✔
 → x₅ entre en base
```
